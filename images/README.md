# Wedding images

Replace the temporary remote image URLs in `index.html` and `styles.css` with these local assets:

- `couple-hero.jpg` — 2400×1600 pixels
- `bride.jpg` — 1200×1500 pixels
- `groom.jpg` — 1200×1500 pixels
- `gallery-1.jpg` through `gallery-6.jpg` — at least 1600 pixels wide each

Update the matching image `src` and gallery `data-full` values when adding files here. The hero background is declared in `styles.css` and should point to `images/couple-hero.jpg`.
